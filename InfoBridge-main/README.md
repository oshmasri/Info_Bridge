# 🌉 InfoBridge

**InfoBridge** is a user-friendly web platform that simplifies access to government services, schemes, loans, and essential documents. It provides clear, step-by-step guidance and official application links, making government processes easier to understand and complete.

---

## 📖 Overview

Many citizens find government procedures confusing due to complex documentation and scattered information across multiple websites. InfoBridge brings everything together in one platform, helping users understand eligibility, required documents, application procedures, and official portals.

---

- 🔐 User Registration & Login

## 🚀 Installation

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/oshmasri/InfoBridge.git
cd InfoBridge
```

---

### 2️⃣ Install Backend Dependencies

```bash
cd backend
npm install
```

---

### 3️⃣ Configure Environment Variables

Create a `.env` file inside the `backend` folder.

```env
PORT=5000

DB_HOST=127.0.0.1
DB_USER=root
DB_PASSWORD=your_password
DB_NAME=infobridge

JWT_SECRET=your_secret_key

GEMINI_API_KEY=your_gemini_api_key
```

---

### 4️⃣ Start Backend

```bash
node server.js
```

---

### 5️⃣ Run Frontend

Open the `frontend/login/index.html` file using **VS Code Live Server**.
